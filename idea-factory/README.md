# Idea Factory

One agent system running many open-data product ideas through the same validation gates in parallel.
Owner: Nick Lektzian. Rules every agent follows: `CLAUDE.md`.

- `core/` shared code (fetcher with cache/retries/budgets, license registry, sample generator, outreach drafts, scoring, lane state, board)
- `lanes/<slug>/` one folder per idea: `LANE.md`, `lane.json`, `sources.json`, `needs_nick.md`, `data/`, `samples/`, `outreach/`
- `ops/` portfolio board and operating files (all regenerated by `python -m core.board` except `INBOX.md`, `AUTOMATIONS.md`, `queue.json`, `needs_nick_global.md`)
- `scripts/tick.py` daily tick, `scripts/digest.py` weekly digest, `scripts/smoke_core.py` proves core on live Detroit permit data

Nothing to install: Python 3.12 standard library only.
